# 🕵️ Coup – Single Player (Java Implementation)

## 🎯 Overview  
This project is a strategic **offline single-player implementation** of the popular board game **Coup**, developed in **Java**. Designed to capture the intrigue, bluffing, and tactical decision-making of the original multiplayer experience, it features AI-controlled opponents that simulate real game dynamics.

## 🧠 Features
- 🤖 **AI-driven opponents** with randomized bluffing and challenge behavior
- 🃏 Full implementation of Coup roles (Duke, Assassin, Captain, Contessa, Ambassador)
- 🎭 Rule-based game logic, including actions, blocks, and challenges
- 🪙 Game economy featuring coin accumulation and coup mechanics
- 🕹️ Basic GUI interface for intuitive gameplay

## 🛠️ Technologies Used
- **Language**: Java 8+
- **Libraries**: Java Swing
- **Structure**: Modular design with clear separation of game logic, player handling, and UI
